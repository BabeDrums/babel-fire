# Babel FIRE

Babel FIRE is an iPhone/iPad-first music-production companion.

- **Live app:** https://babedrums.github.io/babel-fire/
- **Production branch:** `main`
- **Production generation:** V6
- **Isolated successor:** G7 at `/v7-preview/`

For project work, start with [`BABEL_TRUTH.md`](BABEL_TRUTH.md), then [`START_HERE.md`](START_HERE.md). Shared operating/design rules come from the immutable Babel Truth commit pinned there; FIRE-local authority stays in this repo.

Current active documentation is intentionally small: `START_HERE.md`, `AGENTS.md`, `FIRE_CORE.md`, `V6.md`, `V7_DRAFT.md`, and the two G7 certification files. Git/PR history is the archive for retired documentation and prior passes.

The G7 shell is still under certification; `START_HERE.md` always owns the current physical-review/freeze gate.
