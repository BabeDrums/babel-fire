# FIRE → Visual Lab shell handoff

FIRE remains canonical product authority. Visual Lab may reproduce the observable G7 shell comprehensively for experimental validity, but uses isolated Lab-only state and is never a runtime dependency.

## Control baseline

The Lab control should preserve the shell surfaces/interactions whose absence would affect design judgment: Projects, Home, Setup, Structure, Tracks, toolbar actions, project management, inputs/focus, add/edit/reorder/select/confirm, sheets/dialogs, and compact/wide adaptation.

No permanent Lab navigation pills or explanatory footer should be inserted into the FIRE canvas as part of the control condition.

## Promotion

G7 → faithful Lab baseline → parity check → visual candidate → physical comparison → deliberate FIRE implementation → physical FIRE validation → Truth only for transferable rules.
